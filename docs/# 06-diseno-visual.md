# 06-diseno-visual.md

# Objetivo

Actúa como Director Creativo Senior de:

- Apple
- Stripe
- Linear
- Airbnb
- Vercel
- Notion
- Awwwards

Dispones de toda la documentación creada anteriormente:

- Investigación del negocio
- Análisis de fotografías
- Identidad de marca
- Design System
- Arquitectura UX

No contradigas ninguna decisión anterior.

No escribas código.

Debes generar una especificación visual extremadamente detallada que permita a cualquier desarrollador reproducir exactamente la web.

No omitas ningún detalle.

---

# Filosofía visual

La web debe transmitir:

- profesionalidad
- creatividad
- precisión
- calidad
- cercanía
- personalización

El usuario debe percibir inmediatamente que MalagaCrafters convierte cualquier idea en una pieza única.

No debe parecer:

- una tienda online tradicional
- una plantilla de WordPress
- una landing genérica
- una web industrial

Debe sentirse moderna y atemporal.

Inspiración:

Apple

Stripe

Linear

Vercel

No copiar ninguna de ellas.

---

# Dirección artística

Toda la aplicación debe seguir una única dirección artística.

Debe existir coherencia absoluta entre:

fotografías

tipografía

espaciados

fondos

sombras

animaciones

iconografía

cards

CTA

Nunca debe existir la sensación de que distintas secciones han sido diseñadas por personas diferentes.

---

# Hero

Debe ser el elemento visual más potente de toda la web.

Describe exactamente:

estructura

alineación

espacios

proporciones

altura

posición del contenido

fotografía principal

tratamiento fotográfico

fondo

contraste

CTA

animaciones

composición

jerarquía

El Hero debe responder en menos de cinco segundos:

Qué hace MalagaCrafters.

Qué puede conseguir el usuario.

Cómo contactar.

---

# Navbar

Debe transmitir calidad.

Definir:

altura

espaciados

alineaciones

logo

tamaño del logo

márgenes de seguridad

menú

CTA

hover

scroll

sticky

responsive

Nunca reducir el logotipo hasta hacerlo irreconocible.

---

# Alternancia de fondos

Toda la web debe seguir un patrón repetitivo.

Ejemplo:

Sección clara

↓

Sección ligeramente coloreada

↓

Sección blanca

↓

Sección ligeramente coloreada

↓

Footer oscuro

Nunca cambiar colores aleatoriamente.

El usuario debe percibir ritmo visual.

---

# Qué podemos crear

Diseño mediante cards.

Cada card deberá contener:

fotografía

título

breve descripción

iconografía opcional

No utilizar fotografías con tamaños diferentes.

Todas deben compartir:

proporción

sombras

bordes

espaciados

hover

---

# Materiales

La sección debe transmitir calidad.

No parecer una ficha técnica.

Los materiales deben representarse mediante:

fotografías reales

cards

iconografía

etiquetas

No utilizar tablas.

---

# Galería

La galería será el principal elemento visual de toda la web.

Debe sentirse ordenada.

Nunca caótica.

Definir:

número de columnas

proporciones

espaciados

sombras

bordes

hover

animaciones

responsive

Las fotografías deberán mantener:

misma calidad

misma iluminación

mismo tratamiento

misma dirección de luz

No mezclar fotografías con estilos incompatibles.

---

# Cómo trabajamos

Debe ser extremadamente visual.

Representar el proceso mediante:

timeline

cards

iconos

No utilizar grandes bloques de texto.

Cada paso debe poder entenderse en pocos segundos.

---

# Beneficios

Utilizar tarjetas pequeñas.

Cada beneficio debe tener:

icono

título

descripción

Todas compartirán exactamente el mismo diseño.

---

# FAQ

Debe resultar muy limpia.

Los acordeones deben transmitir elegancia.

No utilizar efectos exagerados.

---

# Contacto

Debe ser uno de los elementos visualmente más cuidados.

Mostrar:

Formulario

Correo

Instagram

La composición debe transmitir facilidad.

No añadir elementos innecesarios.

---

# Footer

Debe cerrar la experiencia.

Incluir:

logo

redes sociales

correo

enlaces legales

copyright

No reducir excesivamente el tamaño del logotipo.

Debe mantener el mismo protagonismo que en el Navbar.

---

# Cards

Todas las cards de toda la aplicación deberán reutilizar exactamente el mismo lenguaje visual.

Definir:

padding

radio

sombras

tipografía

espaciados

iconografía

hover

animaciones

Nunca crear variantes visuales sin justificación.

---

# Fotografías

Todas deberán compartir:

misma relación de aspecto

misma iluminación

misma edición

misma saturación

misma nitidez

mismo tipo de recorte

mismo estilo

No utilizar fotografías pixeladas.

No mezclar imágenes oscuras con otras excesivamente claras.

---

# Iconografía

Toda la iconografía deberá compartir:

familia

grosor

color

tamaño

espaciado

Nunca mezclar estilos outline con estilos rellenos.

---

# Tipografía

Toda la web reutilizará exactamente la misma escala tipográfica definida en el Design System.

Nunca crear tamaños nuevos.

El texto normal nunca debe parecer demasiado pequeño.

La lectura debe resultar cómoda incluso en portátiles.

---

# Espaciados

Toda la aplicación reutilizará exclusivamente la escala de espaciados del Design System.

Está prohibido crear márgenes distintos según la sección.

Debe existir una cuadrícula visual clara.

---

# Sombras

Todos los elementos elevados deberán reutilizar únicamente las sombras oficiales del Design System.

Nunca crear sombras específicas para un componente concreto.

---

# Bordes

Todos los componentes equivalentes deberán compartir exactamente el mismo radio.

No mezclar componentes cuadrados con otros excesivamente redondeados.

---

# Colores

Toda la web debe seguir un patrón cromático perfectamente consistente.

Ejemplo:

Color A

↓

Color B

↓

Color C

↓

Color A

↓

Color B

↓

Color C

Nunca:

A

B

C

A

C

A

---

# Ritmo visual

El usuario debe percibir continuidad.

No debe existir sensación de bloques independientes.

Las transiciones entre secciones deben sentirse naturales.

---

# Animaciones

Todas las animaciones deberán compartir:

duración

easing

filosofía

velocidad

Nunca llamar más la atención que el contenido.

Permitir únicamente:

fade

translate

ligero blur

ligera escala

Nunca utilizar:

rebotes

giros

zoom agresivo

destellos

animaciones llamativas

---

# Hover

Las imágenes deberán responder ligeramente al cursor.

Ejemplos:

pequeño zoom

ligera elevación

incremento muy suave de sombra

leve mejora del contraste

Todos los hover deberán compartir exactamente la misma duración.

---

# Responsive

Describe completamente el comportamiento para:

Desktop XL

Desktop

Laptop

Tablet

Mobile

No debe sentirse como una adaptación improvisada.

Debe parecer exactamente la misma web.

---

# Accesibilidad

Todo el diseño deberá cumplir WCAG AA.

Definir:

contrastes

focus

lectura

teclado

áreas táctiles

formularios

iconografía

---

# SEO visual

Las decisiones visuales deberán favorecer:

lectura rápida

escaneo

estructura semántica

tiempo de permanencia

No sacrificar la experiencia por elementos decorativos.

---

# Escalabilidad

Todo el diseño deberá permitir añadir nuevas secciones manteniendo exactamente la misma identidad.

No crear estilos imposibles de reutilizar.

---

# Revisión final

Antes de considerar terminado el diseño comprobar:

✓ Branding

✓ Colores

✓ Tipografía

✓ Espaciados

✓ Grid

✓ Fotografías

✓ Logotipo

✓ Cards

✓ CTA

✓ Formularios

✓ Navbar

✓ Footer

✓ Animaciones

✓ Responsive

✓ Accesibilidad

✓ Consistencia

Si algún elemento rompe la armonía visual deberá modificarse antes de dar el diseño por finalizado.

---

# Resultado esperado

El documento debe describir absolutamente toda la dirección artística de la web.

Debe permitir que cualquier desarrollador reproduzca exactamente el diseño sin tomar decisiones creativas adicionales.

No escribir código.
