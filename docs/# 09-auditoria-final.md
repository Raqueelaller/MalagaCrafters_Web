# 09-auditoria-final.md

# Objetivo

Actúa como un equipo formado por:

- Director Creativo Senior
- UX Lead
- UI Lead
- Frontend Staff Engineer
- Software Architect
- QA Engineer
- Especialista SEO
- Especialista en Accesibilidad
- Especialista en Performance

No escribas código.

No implementes mejoras.

Únicamente realiza una auditoría completa del proyecto antes de entregarlo al cliente.

Debes analizar absolutamente toda la aplicación.

No omitas ningún detalle.

No des nada por supuesto.

---

# Objetivo de la auditoría

Comprobar que la web puede entregarse a un cliente real.

Debe parecer desarrollada por un estudio profesional.

Si detectas cualquier problema, indícalo.

No suavices las críticas.

---

# Branding

Analiza:

- personalidad
- coherencia
- tono
- propuesta de valor
- diferenciación
- identidad

Comprueba que toda la web transmite exactamente la misma marca.

Detecta cualquier incoherencia.

# Restricción

No des el proyecto por finalizado simplemente porque funcione.

El objetivo es entregar una web que un estudio profesional estaría orgulloso de presentar a un cliente.

Debe parecer un producto comercial, no un ejercicio académico.
