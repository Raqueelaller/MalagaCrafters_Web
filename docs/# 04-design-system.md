# 04-design-system.md

# Objetivo

Actúa como un Design System Lead de una empresa tecnológica como:

- Apple
- Stripe
- Linear
- Airbnb
- Vercel
- Notion

Dispones de:

- investigación del negocio
- análisis de fotografías
- identidad de marca

Debes crear un Design System profesional que sirva como única referencia visual durante todo el desarrollo.

No escribas código.

No diseñes todavía ninguna página.

Todo debe justificarse desde el punto de vista del branding.

---

# Filosofía

El Design System debe cumplir los siguientes objetivos:

- máxima consistencia
- máxima reutilización
- facilidad de mantenimiento
- escalabilidad
- accesibilidad
- rendimiento
- coherencia visual

Toda la aplicación deberá parecer diseñada por un único Director de Arte.

Nunca deberá parecer una plantilla.

# Reutilización

Está completamente prohibido crear variantes innecesarias.

Si existe un componente equivalente:

debe reutilizarse.

No duplicar componentes.

No duplicar estilos.

No duplicar sombras.

No duplicar botones.

No duplicar cards.

---

# Escalabilidad

El sistema deberá permitir:

añadir nuevas páginas

añadir nuevos materiales

añadir nuevos tipos de trabajos

añadir nuevas galerías

sin romper la coherencia visual.

---

# Resultado esperado

El documento debe definir un Design System completo, listo para ser implementado.

No escribir código.
