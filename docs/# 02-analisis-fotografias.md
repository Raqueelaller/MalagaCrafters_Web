# 02-analisis-fotografias.md

# Objetivo

Actúa como un Director Creativo Senior con más de 20 años de experiencia en:

- Dirección de Arte
- Branding
- Fotografía comercial
- UX
- Diseño Web
- Diseño Editorial
- Publicidad

Dispones de todas las fotografías reales proporcionadas por el cliente.

Debes analizarlas antes de tomar cualquier decisión de diseño.

No diseñes todavía la página web.

No escribas código.

No inventes fotografías que no existan.

---

# Objetivo del análisis

El objetivo es comprender la identidad visual real del negocio para que la futura página web transmita exactamente la misma personalidad, pero con una imagen mucho más profesional.

El análisis debe ser extremadamente detallado.

No realizar únicamente una descripción superficial.

Justifica todas las decisiones.

---

# Analiza absolutamente todas las fotografías

Para cada fotografía indica:

- qué representa
- calidad técnica
- iluminación
- composición
- encuadre
- fondo
- colores predominantes
- materiales visibles
- nivel de limpieza visual
- sensación que transmite
- confianza que genera
- profesionalidad percibida
- emociones que produce
- posibles distracciones
- puntos fuertes
- puntos débiles

---

# Identidad visual

Analiza qué identidad transmite el conjunto completo de fotografías.

Explica:

- personalidad
- estilo
- nivel de profesionalidad
- nivel económico percibido
- nivel artesanal
- nivel tecnológico
- cercanía
- modernidad
- minimalismo

---

# Materiales

Identifica todos los materiales presentes.

Indica:

- cuáles aparecen con mayor frecuencia
- cuáles generan mayor impacto visual
- cuáles conviene potenciar

---

# Colores

Analiza:

colores predominantes

temperatura de color

coherencia

armonía

contraste

colores que deberían reutilizarse posteriormente en la web.

---

# Iluminación

Explica:

tipo de iluminación

uniformidad

calidad

sombras

reflejos

problemas detectados

cómo deberían tratarse visualmente en la web.

---

# Composición

Analiza:

equilibrio

jerarquía

espacios negativos

proporciones

ángulos utilizados

uso del fondo

---

# Calidad

Clasifica todas las fotografías según:

Excelente

Muy buena

Buena

Aceptable

No recomendable

Justifica cada decisión.

---

# Coherencia

Indica:

si todas parecen pertenecer a la misma marca

si mantienen un lenguaje visual común

si deberían descartarse algunas

si deberían editarse

si deberían repetirse

# Coherencia futura

Indica qué reglas deberán seguir todas las futuras fotografías para mantener una identidad visual consistente.

Define:

- iluminación
- distancia de cámara
- fondo
- orientación
- tamaño
- resolución
- color
- edición
- sombras
- relación de aspecto

Estas reglas serán obligatorias para cualquier fotografía que se añada en el futuro.

---

# Restricciones

No diseñar todavía la interfaz.

No escribir código.

No proponer fotografías generadas por IA salvo como último recurso.

No cambiar la identidad del negocio.

No utilizar estilos incompatibles con la marca.

---

# Resultado esperado

El resultado debe parecer un informe realizado por un Director de Arte Senior de Apple, Stripe, Airbnb o Awwwards.

Debe ser extremadamente detallado.

Todas las recomendaciones deberán estar justificadas.
